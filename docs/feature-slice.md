# Stewart Feature Slice

## Purpose

Define the smallest meaningful version of Stewart that demonstrates the core concept for the hackathon.

## Included Features

### Conversational Stewardship

A writer can present a creative proposal directly to Stewart.

### Clarification Loop

Stewart identifies missing information and asks questions before beginning or continuing an investigation.

### Specialist Agent Coordination

Stewart dynamically delegates investigation to specialized agents:

- Lore Agent
- Timeline Agent
- Relationship Agent
- Impact Agent

### Dynamic Discovery

Specialist agents discover relevant information at runtime using connected knowledge sources.

### Multi-Agent Analysis

Specialists provide findings back to Stewart, who synthesizes the results.

### Stewardship Report

Stewart presents:

- Findings
- Risks
- Opportunities
- Options
- Tradeoffs

The human creator remains the final decision-maker.

## Excluded from MVP

The following are intentionally out of scope:

- Permanent universe knowledge storage
- Historical investigation archive
- Full fictional universe graph database
- Automated creative approval or rejection
- Production-scale governance workflows
- Enterprise user management

## Success Criteria

The MVP succeeds if it demonstrates that an agentic system can help humans evaluate complex creative decisions by coordinating specialized analysis rather than simply retrieving information.
